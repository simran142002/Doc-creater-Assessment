Error codes

CodeStatusMeaning
VALIDATION400The request is malformed: bad JSON, a missing or wrong field, a value out of range. details.issues lists Zod issues when present.
UNAUTHENTICATED401No valid session. Sign in again.
FORBIDDEN403You can see this document but your role can't do this, or the request came from another site.
NOT_FOUND404The document doesn't exist or you have no access to it (the two look the same on purpose). Also used for a share that isn't there.
STALE_VERSION409Someone saved first. details.current carries their version, who saved and the full doc.
CONFLICT New409A database uniqueness rule was hit. Retry after reloading.
PAYLOAD_TOO_LARGE413Body over ~1 MB, content over 1 MB, upload over 2 MB, or an import with more than 10,000 lines/paragraphs.
UNSUPPORTED_TYPE415Upload isn't .txt, .md or .docx, or its MIME type contradicts the extension.
INVALID_CONTENT422Content doesn't fit the editor's schema, or is nested too deeply.
EMPTY_FILE422The upload is empty or has no readable text.
CORRUPT_FILE422Damaged .docx, text that isn't UTF-8/UTF-16, or a binary file renamed to .txt.
SELF_SHARE422The owner tried to share with themself.

Not handled, on purpose

  • Revoke racing a save. A save that passed its access check a few milliseconds before the owner revoked still lands. Closing that window needs the role check inside the UPDATE; one request of overlap is acceptable here.
  • Non-UTF-8 text encodings (Latin-1, Windows-1252) are rejected with a clear message instead of guessed, because guessing silently corrupts accented text.
  • Zip bombs. A .docx is capped at 2 MB compressed and 1 MB of resulting content, but mammoth still inflates it in memory first.
  • Shared rate limits. Limits are in memory per serverless instance, so they are best-effort. Session revocation lists are out of scope.
  • sendBeacon can only POST, so it can't call the PATCH route. The client doesn't use it; it flushes with fetch + keepalive. If that ever changes, the route already accepts text/plain bodies but would need a POST alias.
  • Duplicate block ids sent through the API are not de-duplicated; the editor's UniqueID extension prevents them in normal use.
